# DevOps_Homelab

A local homelab project where I'm learning core DevOps skills- Linux, networking, containers, and orchestration on my laptop.

## What this is ?

I'm building homelab on one machine (no extra hardware) to understand how the pieces actually work before automating them. This repo is where I'm tracking that process.

This is Project 1 of two. The second project (deploying and automating same Robot Shop app on AWS) comes later, once this one is done.

## What's covered

- Linux and basic networking
- Containers with Podman
- Orchestration with k3s and Helm
- Automation with Ansible
- Monitoring with Prometheus and Grafana

## Environment

- OS: Fedora 44 Workstation
- Hardware: single laptop, 16GB RAM
- Container runtime: Podman
- Demo app: [Robot Shop](https://github.com/instana/robot-shop)
